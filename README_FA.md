# مدرسه هوشمند — سورس اولیه اندروید

این پروژهٔ اولیه Kotlin + Jetpack Compose است و رابط فارسی، صفحه ورود با کد دعوت آزمایشی و داشبورد ساده دارد.

**این فایل ZIP سورس پروژه است، نه APK آماده.** برای ساخت APK باید پروژه را با Android Studio و Android SDK باز و Build کنید.

کد دعوت آزمایشی: `MADRESE-2026`

هشدار: کد دعوت در این نسخه داخل برنامه است و امنیت واقعی ندارد. پیش از استفادهٔ مدرسه‌ای باید ورود و دعوت‌ها در سرور امن بررسی شوند و داده‌های دانش‌آموزان روی سرور امن نگهداری شوند.
